# Heart Disease Prediction Using Machine Learning Algorithms

## Project Overview

This project predicts the presence of heart disease using Machine Learning algorithms. The model analyzes patient health parameters such as age, cholesterol, blood pressure, heart rate, and other medical attributes to determine the likelihood of heart disease.

## Objectives

* Predict heart disease using Machine Learning.
* Compare different classification algorithms.
* Improve early disease detection.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Algorithms Used

* Logistic Regression
* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)

## Dataset

Heart Disease Dataset containing patient medical records and health parameters.

## How to Run

1. Install required libraries:
   pip install -r requirements.txt

2. Run the Python file:
   python heart_disease_prediction.py

## Output

The system predicts whether a patient has heart disease and displays the model accuracy.
